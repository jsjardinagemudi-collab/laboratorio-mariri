# A Luz do Mariri — Laboratório V6

Atualização incremental da V5 para testar confirmação de ordens e formação inicial.

- Início com **3.000 Luz, 3.000 Mariri e 3.000 Chacrona**.
- Os 16 Guias iniciam no **nível 16, 420 XP** e 100 de Vitalidade.
- **Nenhuma equipe é pré-criada**: a Equipe 1 nasce quando o jogador escolhe o Guia, via criatura ou terreno.
- Criaturas não atacam por aproximação neste laboratório: batalha somente após confirmar **Atacar** e escolher equipe.
- O mundo pausa enquanto um menu está aberto.
- Mantidos ícones das equipes, equipes cooperativas, defesa automática e permanência no local após combate.

## Publicação
Substitua index.html e README.md no repositório laboratorio-mariri, raiz da branch publicada no GitHub Pages.
